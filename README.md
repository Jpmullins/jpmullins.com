# Justin P. Mullins

Personal research website at https://jpmullins.com.

Buildless HTML, CSS, and JavaScript, hosted with GitHub Pages.

## Updating

Edit `index.html`, `styles.css`, or `script.js` on the `main` branch. GitHub Pages publishes the repository root. Preserve `CNAME` when updating the site.

## Local preview

Run `python3 -m http.server 8000` from the repository directory, then open http://localhost:8000.
